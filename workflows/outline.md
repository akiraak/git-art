# 記事構成の作成

## 前提

- リポジトリが `projects/{プロジェクト名}/repo/` にクローン済みであること
- `projects/{プロジェクト名}/config.json` が作成済みであること

## 手順

1. 利用者に「どんな構成にしたいか」を自由入力で聞く
2. `projects/{プロジェクト名}/repo/` 配下のリポジトリ内容を読み取る
3. リポジトリ内容 + config.json + 利用者の入力をもとに、構成案（大見出し・小見出し）を作成する
4. 構成案を `projects/{プロジェクト名}/outlines/v{N}.md` に保存する（初回は v1）
5. 構成案をコードブロックで囲んでコンソールに表示する（`#` などのマークアップ記号がそのまま見える状態にする）
6. 利用者に承認かフィードバック（自由入力）かを選んでもらう
   - **フィードバック** → 構成を修正し、バージョン番号を上げて `outlines/v{N+1}.md` として保存する（ステップ5に戻る）
   - **承認** → 完了（最新の v{N}.md が確定版）

## outlines/v{N}.md の形式

```markdown
# 記事タイトル

## 大見出し1

### 小見出し1-1
### 小見出し1-2

## 大見出し2

### 小見出し2-1

---

## 変更履歴

### v1 → v2
- 変更内容と理由

### v2 → v3
- 変更内容と理由
```

- 上部に最新の記事構成を記載する
- `---` 以降に変更履歴を蓄積する（初回 v1 では変更履歴なし）
- フィードバックによる構成変更時、構成を更新しつつ変更履歴を追記する
