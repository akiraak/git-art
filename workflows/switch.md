# プロジェクト切り替え

## 手順

1. `projects/` 配下のディレクトリ一覧を取得する（`current.json` は除く）
2. 現在のプロジェクト（`current.json`）を表示する
3. 各プロジェクトの進捗ステータスを判定する
4. プロジェクト一覧を番号付き・進捗ステータス付きで表示する
5. 利用者に切り替え先を選んでもらう
6. `projects/current.json` を更新する

## 進捗ステータスの判定

各プロジェクトディレクトリの中身を確認し、以下の順で判定する。

| 条件 | ステータス表示 |
|------|---------------|
| `articles/` にファイルがある | `記事 v{最大番号} / 構成 v{最大番号}` |
| `outlines/` にファイルがある | `構成 v{最大番号} / 記事未生成` |
| `config.json` がある | `設定済み / 構成未作成` |
| 上記いずれもない | `クローン済み` |
