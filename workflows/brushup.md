# 記事ブラッシュアップ

## 前提

- `projects/{プロジェクト名}/articles/` に記事が保存済みであること
- `projects/{プロジェクト名}/outlines/` に構成が保存済みであること

## 手順

1. `projects/{プロジェクト名}/articles/` ディレクトリから最大バージョン番号の `v{N}.md` を読む
2. `projects/{プロジェクト名}/outlines/` ディレクトリから最大バージョン番号の `v{N}.md` を読む
3. 利用者にフィードバックを質問する
4. フィードバックに基づいて outline を更新し、`outlines/v{N+1}.md` として保存する
5. 更新した outline の構成をコンソールに表示する
6. 変更点（何を・なぜ変更したか）をコンソールに表示する
7. 利用者に承認かフィードバック（自由入力）かを選んでもらう
   - **フィードバック** → outline を修正し、バージョン番号を上げて保存する（ステップ5に戻る）
   - **承認** → 次のステップへ進む
8. 承認された outline に基づいて記事を更新し、`articles/v{N+1}.md` として保存する

## outline の更新内容

- 構成（見出し）に変更があれば上部の構成を更新する
- 変更履歴セクションに、バージョン番号・変更内容・理由を追記する

## 繰り返し

利用者が満足するまで手順 1〜8 を繰り返す。
