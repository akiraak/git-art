# 記事ブラッシュアップ

## 前提

- `projects/{プロジェクト名}/article.md` が作成済みであること
- `projects/{プロジェクト名}/history.md` が作成済みであること

## 手順

1. `projects/{プロジェクト名}/article.md` の現在の内容を読む
2. 利用者にフィードバックを質問する
3. フィードバックに基づいて `article.md` を更新する
4. `history.md` に新しいバージョンを追記する

## history.md の追記形式

```markdown
## v{N} - {日付}

- 変更内容の要約
- フィードバック: 「利用者のフィードバック内容」
```

## 繰り返し

利用者が満足するまで手順 1〜4 を繰り返す。
