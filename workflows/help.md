# ヘルプ

## 手順

### 「ヘルプ」「使い方」「何ができる？」の場合

利用者に以下の内容を表示する。

---

GitHub リポジトリの内容をもとに記事を作成するツールです。

GitHub URL を送るだけで、質問に何個か答えれば記事が生成されます。

例：`https://github.com/user/repo`

詳しく知りたい場合は教えてください。

---

### 「もっと詳しく」の場合

利用者に以下の内容を表示する。

---

GitHub URL を送ると、こんな流れで記事ができます：

1. リポジトリの中身を取得
2. 記事の方向性をいくつか質問
3. 見出しの構成を一緒に決める
4. 記事を生成
5. 気になるところがあれば何度でも修正

記事ができたあとも、フィードバックを伝えれば何度でも改善できます。

---
