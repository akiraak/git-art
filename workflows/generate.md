# 記事生成

## 前提

- リポジトリが `projects/{プロジェクト名}/repo/` にクローン済みであること
- `projects/{プロジェクト名}/config.json` が作成済みであること
- `projects/{プロジェクト名}/outlines/` に構成案が保存済みであること

## 手順

1. 全体設定 `config.json` とプロジェクト設定 `projects/{プロジェクト名}/config.json` を読み、記事の設定を確認する（プロジェクト設定の項目を優先する）
2. `projects/{プロジェクト名}/outlines/` ディレクトリから最大バージョン番号の `v{N}.md` を読み、記事の構成を確認する
3. `projects/{プロジェクト名}/repo/` 配下のリポジトリ内容を読み取る
   - README.md やドキュメント
   - ソースコードの構成とキーファイル
   - package.json 等の設定ファイル
4. outline の構成に従い、config.json の設定に基づいて記事を作成する
   - **アウトラインが最優先**: 見出し構成・セクション構成はアウトラインに厳密に従う。過去バージョンの記事を参考にしてもよいが、アウトラインと矛盾する場合はアウトラインを優先する
   - **記事の種類** に応じた構成にする
   - **対象読者** のレベルに合わせた説明の深さにする
   - **トーン** に合わせた文体で書く
   - **追加の要望** があれば反映する
5. 記事を `projects/{プロジェクト名}/articles/v{N}.md` に保存する（outline と同じバージョン番号）
6. 生成した記事ファイルのフルパスを利用者に表示する
