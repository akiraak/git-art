# 記事生成

## 前提

- リポジトリが `projects/{プロジェクト名}/repo/` にクローン済みであること
- `projects/{プロジェクト名}/config.json` が作成済みであること

## 手順

1. `projects/{プロジェクト名}/config.json` を読み、記事の設定を確認する
2. `projects/{プロジェクト名}/repo/` 配下のリポジトリ内容を読み取る
   - README.md やドキュメント
   - ソースコードの構成とキーファイル
   - package.json 等の設定ファイル
3. config.json の設定に基づいて記事を作成する
   - **記事の種類** に応じた構成にする
   - **対象読者** のレベルに合わせた説明の深さにする
   - **トーン** に合わせた文体で書く
   - **追加の要望** があれば反映する
4. 記事を `projects/{プロジェクト名}/article.md` に保存する
5. `projects/{プロジェクト名}/history.md` を作成し、v1 として記録する
6. 生成した記事ファイルのフルパスを利用者に表示する

## history.md の初期形式

```markdown
# 変更履歴

## v1 - {日付}

初回作成
```
