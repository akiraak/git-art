# 記事設定の収集

## 前提

- リポジトリが `projects/{プロジェクト名}/repo/` にクローン済みであること

## 手順

1. 利用者に以下を質問する
   - **記事の種類**: 技術解説 / プロジェクト紹介 / チュートリアル / その他（自由入力）
   - **対象読者**: 初心者 / 中級者 / 上級者
   - **記事のトーン**: カジュアル / フォーマル / 技術的
   - **追加の要望**: 自由入力（任意）
2. 回答を以下の形式で `projects/{プロジェクト名}/config.json` に保存する

## config.json の形式

```json
{
  "articleType": "プロジェクト紹介",
  "targetAudience": "中級者",
  "tone": "フォーマル",
  "additionalNotes": ""
}
```
