# 記事設定の収集

## 前提

- リポジトリが `projects/{プロジェクト名}/repo/` にクローン済みであること

## 設定の2階層

- **全体設定** (`config.json`): すべての記事に共通するデフォルト設定
- **プロジェクト設定** (`projects/{プロジェクト名}/config.json`): 記事ごとの個別設定

プロジェクト設定に指定がある項目は全体設定より優先される。

## 手順

1. 全体設定 `config.json` が存在する場合、現在の全体設定を表示する
2. 利用者に「この記事はどのような方向性にしますか？」と質問する
   - 例: 「初心者向けにカジュアルな紹介記事」「技術的な解説記事」など
   - 全体設定と異なる口調・文体にしたい場合はここで指定してもらう
3. 回答を `projects/{プロジェクト名}/config.json` に保存する

## 全体設定 config.json の形式

```json
{
  "tone": "デフォルトの口調（例: フレンドリーだけど丁寧）",
  "style": "デフォルトの文体（例: ですます調）",
  "notes": "その他の共通設定があれば記載"
}
```

## プロジェクト設定 config.json の形式

```json
{
  "description": "記事の方向性",
  "tone": "この記事の口調（省略時は全体設定を使用）",
  "style": "この記事の文体（省略時は全体設定を使用）",
  "notes": "その他の個別設定があれば記載"
}
```
