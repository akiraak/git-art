# 全体設定

## 概要

すべての記事に共通するデフォルトの口調・文体などを管理する。

## 手順

1. `config.json` が存在するか確認する
   - 存在する場合、現在の設定内容を表示する
   - 存在しない場合、その旨を伝える
2. 利用者に変更したい内容を質問する
   - 新規作成の場合: デフォルトの口調・文体の好みを聞く
   - 変更の場合: 何を変更したいか聞く
3. `config.json` を作成または更新する

## config.json の形式

```json
{
  "tone": "デフォルトの口調（例: フレンドリーだけど丁寧）",
  "style": "デフォルトの文体（例: ですます調）",
  "notes": "その他の共通設定があれば記載"
}
```

## 呼び出しキーワード

「設定を変えたい」「口調を変えたい」「全体設定」など。
