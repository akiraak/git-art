# リポジトリ取得

## 入力

- GitHub リポジトリ URL
- 記事の名前（利用者が自由入力）

## プロジェクト名の命名規則

プロジェクト名は `{記事の名前}-{リポジトリ名}-{タイムスタンプ}` の形式で自動生成する。

- タイムスタンプ形式: `YYYYMMDD-HHMMSS`
- 例: 利用者が「紹介記事」と入力、リポジトリが `git-art` → `紹介記事-git-art-20260214-143000`

## 手順

1. 利用者から GitHub リポジトリ URL を受け取る
2. URL からリポジトリ名を抽出する（例: `https://github.com/user/repo` → `repo`）
3. 利用者に記事の名前を質問する
4. プロジェクト名を `{記事の名前}-{リポジトリ名}-{タイムスタンプ}` で生成する
5. `projects/{プロジェクト名}/` ディレクトリを作成する
6. `git clone {URL} projects/{プロジェクト名}/repo/{リポジトリ名}` を実行する
7. クローンの成功を確認する

## 出力

- `projects/{プロジェクト名}/repo/{リポジトリ名}/` にリポジトリがクローンされる

## エラー時

- URL が不正な場合は利用者に再入力を求める
