# リポジトリ取得

## 入力

- プロジェクト名
- GitHub リポジトリ URL

## 手順

1. 利用者からプロジェクト名と GitHub リポジトリ URL を受け取る
2. URL からリポジトリ名を抽出する（例: `https://github.com/user/repo` → `repo`）
3. `projects/{プロジェクト名}/` ディレクトリを作成する
4. `git clone {URL} projects/{プロジェクト名}/repo/{リポジトリ名}` を実行する
5. クローンの成功を確認する

## 出力

- `projects/{プロジェクト名}/repo/{リポジトリ名}/` にリポジトリがクローンされる

## エラー時

- URL が不正な場合は利用者に再入力を求める
- ディレクトリが既に存在する場合は利用者に確認する
