# git-art

GitHub リポジトリの内容を読み取り、対話的に記事を作成するツール。

## 概要

git-art は、指定した GitHub リポジトリのコードやドキュメントを解析し、その内容に基づいた記事を生成します。利用者との対話を通じて記事の方向性を決定し、編集を繰り返しながら記事を完成させます。

## 特徴

- GitHub リポジトリの URL を指定するだけで、コード・ドキュメントを自動で読み取り
- 利用者への質問を通じて記事の種類・対象読者・トーンを決定
- ドラフト作成後、フィードバックに基づく反復的な編集
- 技術解説、チュートリアル、紹介記事など多様な記事形式に対応

## 使い方

1. 対象の GitHub リポジトリ URL を指定する
2. 質問に答えて記事の方向性を決める
3. 生成されたドラフトを確認する
4. フィードバックを伝えて記事を改善する
5. 完成した記事を取得する
