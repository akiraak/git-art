# git-art

GitHub リポジトリの内容を読み取り、Claude Code で対話的に記事を作成するツール。

## 概要

git-art は、指定した GitHub リポジトリのコードやドキュメントを解析し、その内容に基づいた記事を生成します。Claude Code がワークフロー定義（`workflows/`）に従って処理を実行し、利用者との対話を通じて記事を完成させます。

## 特徴

- GitHub リポジトリの URL を指定するだけで、コード・ドキュメントを読み取り
- 利用者への質問を通じて記事の種類・対象読者・トーンを決定
- フィードバックに基づく反復的な記事改善
- 変更履歴を history.md で管理

## 使い方

Claude Code のセッション内で以下のように指示します。

1. 「{プロジェクト名} で {GitHub URL} の記事を作成して」→ リポジトリ取得・設定・記事生成
2. 「記事をブラッシュアップして」→ フィードバックに基づく改善

## ワークフロー

各処理は `workflows/` 配下の Markdown ファイルで定義されています。

| ファイル | 処理内容 |
|---------|---------|
| `workflows/clone.md` | リポジトリの取得 |
| `workflows/config.md` | 記事設定の収集 |
| `workflows/generate.md` | 記事の生成 |
| `workflows/brushup.md` | 記事のブラッシュアップ |
